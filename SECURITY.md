# Bezpieczeństwo AVA Security

## Status projektu
AVA Security jest prototypem. Nie zapewnia jeszcze ochrony antywirusowej, ciągłego monitorowania telefonu ani automatycznej reakcji na ataki.

## Zgłaszanie podatności
Nie publikuj publicznie szczegółów luk bezpieczeństwa, haseł ani prywatnych danych.

Jeżeli dostępna jest funkcja GitHub Security → Report a vulnerability, użyj prywatnego zgłoszenia. Jeśli jej nie ma, zgłoś potrzebę ustanowienia bezpiecznego kanału kontaktu, bez ujawniania szczegółów podatności.

## Podstawowe zasady
- Nie umieszczaj kluczy API ani haseł w publicznym repozytorium.
- Każdy serwer AI musi posiadać autoryzację, ograniczenia użycia i kontrolę kosztów.
- Nie publikuj rozmów ani danych osobowych bez zgody.
- Nie uruchamiaj automatycznie niezweryfikowanego kodu od osób trzecich.
- Nie przedstawiaj porad bezpieczeństwa jako potwierdzonego wykrycia ataku.
- Aktualizacje i zmiany bezpieczeństwa wymagają przeglądu przed publikacją.
