# Jak współtworzyć AVA Security

AVA Security to społecznościowy projekt polskojęzycznej asystentki AI. Zapraszamy programistów, projektantów, testerów i osoby z pomysłami.

## Jak dołączyć
1. Sprawdź istniejące Issues.
2. Zgłoś pomysł lub błąd przez GitHub Issues.
3. Większe zmiany najpierw omów ze społecznością.
4. Kod zgłaszaj przez Pull Request.
5. Opisz, co zmieniłeś i jak sprawdziłeś działanie.

## Zasady bezpieczeństwa
- Nie publikuj haseł, tokenów ani kluczy API.
- Nie dodawaj ukrytego śledzenia i nie zbieraj danych bez zgody.
- Testuj nowe funkcje oddzielnie, żeby nie zepsuć działającej AVA.
- Zmiany dotyczące mikrofonu, kont i prywatności wymagają uzasadnienia.
- Wszystkie zmiany są sprawdzane przed zaakceptowaniem.

## Licencja i współpraca
Przed przyjmowaniem zewnętrznych zmian kodu ustalimy licencję i zasady wkładu. Na razie zapraszamy do zgłaszania pomysłów i testowania.

## Nasza społeczność
Współpracujemy z szacunkiem. Każdy może się uczyć i rozwijać projekt.
